Azkar Bot — Privacy Policy

سياسة الخصوصية الخاصة ببوت الأذكار

نظرة عامة

Azkar Bot هو بوت ديسكورد إسلامي (تطوير Wano Studio) يقوم بإرسال أذكار وأدعية دورية تلقائيًا في قناة يحددها أدمن السيرفر. توضح هذه الصفحة ما هي البيانات التي يجمعها البوت، وكيف تُستخدم، وكيف يمكنك طلب حذفها.

البيانات التي نجمعها

  • معرّف السيرفر (Guild ID) واسم السيرفر
  • معرّف القناة (Channel ID) المحددة لإرسال الأذكار
  • إعدادات السيرفر: اللغة المختارة (عربي/إنجليزي)، توقيت إرسال الأذكار
  • حالة "بوستر" (Server Booster) لأعضاء سيرفر الدعم الرسمي فقط، لعرضها في لوحة تحكم مالك البوت
  • محتوى الرسائل: يُقرأ لحظيًا فقط للتحقق من بادئة الأوامر النصية ("+")، ولا يُخزَّن أو يُسجَّل أبدًا

كيف نخزّن البيانات

تُخزَّن البيانات في قاعدة بيانات MongoDB (مع نسخة احتياطية محلية بصيغة JSON) على خوادمنا الخاصة. لا تُشارك هذه البيانات مع أي طرف ثالث، ولا تُستخدم لأغراض إعلانية أو تسويقية، ولا تُستخدم لتدريب أي نماذج ذكاء اصطناعي.

مدة الاحتفاظ بالبيانات

تبقى بيانات السيرفر مخزَّنة طالما البوت مضافًا للسيرفر. عند إزالة البوت من السيرفر، تُحذف كل البيانات المرتبطة بذلك السيرفر تلقائيًا وفوريًا من قاعدة البيانات.

طلب حذف البيانات

يمكن حذف بياناتك بإحدى الطرق التالية:

  • إزالة البوت من سيرفرك — يحذف هذا كل بيانات السيرفر فورًا وتلقائيًا
  • التواصل المباشر مع المطور لطلب حذف يدوي لأي بيانات إضافية (مثل حالة البوستر)

الأمان

نتخذ إجراءات معقولة لحماية البيانات المخزَّنة من الوصول غير المصرح به، بما يشمل تقييد الوصول لقاعدة البيانات على فريق التطوير فقط.

تعديلات على هذه السياسة

قد تُحدَّث هذه السياسة من وقت لآخر لتعكس أي تغييرات في وظائف البوت. سيُشار إلى تاريخ آخر تحديث أسفل هذه الصفحة.

Overview

Azkar Bot is an Islamic Discord bot (developed by Wano Studio) that automatically sends periodic azkar and duas to a channel chosen by the server admin. This page explains what data the bot collects, how it is used, and how you can request its deletion.

Data We Collect

  • Guild ID and guild name
  • Channel ID selected for sending azkar
  • Guild settings: chosen language (Arabic/English), sending interval
  • Server Booster status for members of our official support server only, displayed in the owner-only dashboard
  • Message content: read momentarily only to check for the command prefix ("+"), never stored or logged

How We Store Data

Data is stored in a MongoDB database (with a local JSON fallback) on our own servers. This data is never shared with third parties, never used for advertising or marketing, and never used to train any AI/ML models.

Data Retention

Guild data remains stored for as long as the bot is present in that server. When the bot is removed from a server, all data associated with that server is automatically and immediately deleted from our database.

Requesting Data Deletion

You can have your data deleted through either of these methods:

  • Remove the bot from your server — this instantly and automatically deletes all data for that server
  • Contact the developer directly to request manual deletion of any additional data (e.g. booster status)
Discord: @oldmaro Support server: discord.gg/NvGxMeNP6t

Security

We take reasonable measures to protect stored data from unauthorized access, including restricting database access to the development team only.
