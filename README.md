<h2>
<img width="22" src="https://api.iconify.design/lucide/info.svg?color=%23e0c274" valign="middle"/>
&nbsp;Overview
</h2>

This repository hosts the **Privacy Policy page** for **Azkar Bot** — an Islamic Discord bot developed by **Wano Studio** that automatically sends periodic azkar and duas to a channel chosen by the server admin.

The page is built with a dark glassmorphism design, fully bilingual (Arabic / English), and clearly explains what data the bot collects, how it's stored, and how it can be deleted — with no unnecessary complexity.
